# Consórcios na Prática

Site oficial: [consorciosnapratica.com.br](https://consorciosnapratica.com.br)

## Sobre o projeto

Site pessoal e profissional voltado para consórcios, reunindo conteúdo, orientações e contato para quem busca entender melhor o funcionamento de consórcios e tomar decisões mais seguras na hora de comprar uma carta.

## Objetivo

Apresentar de forma clara o trabalho, a experiência e os serviços relacionados a consórcio, servindo como ponto de contato central para leads e clientes vindos das redes sociais (@consorcionapratica) e de buscas diretas pelo domínio.

## Estrutura do site

| Seção | Descrição |
|---|---|
| Início | Apresentação geral e proposta de valor |
| Sobre | Trajetória e experiência na área de consórcios |
| Conteúdo | Artigos, dicas e materiais educativos sobre consórcio |
| Contato | Formulário ou link direto para WhatsApp/Instagram |

*Estrutura sujeita a ajustes conforme o site evolui.*
